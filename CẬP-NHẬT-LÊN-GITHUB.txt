 BƯỚC 1 — UPLOAD CODE R5 LÊN GITHUB
================================================================
CÁCH A — CHUẨN NHẤT (upload toàn bộ, khuyên dùng):
 1. Giải nén oes-vercel.zip ra máy.
 2. Mở repo GitHub → "Add file" → "Upload files".
 3. Kéo thả TOÀN BỘ file + thư mục (GitHub tự ghi đè file trùng tên).
 4. Commit: "OES R5 - tach du lieu Vercel" → Commit changes.
 5. Chờ Vercel tự deploy ~1 phút.

CÁCH B — NHANH (chỉ thay 4 file, áp dụng khi repo đã chạy được):
  Upload ghi đè 4 file sau từ bản zip:
      src/config.js             (hậu tố tên file + khóa phiên ổn định)
      src/store/dataStore.js    (đọc/ghi theo tên file có hậu tố)
      src/drive/driveClient.js  (chẩn đoán Drive hiểu tên có hậu tố)
      src/routes/public.routes.js (build marker R5 để xác minh)
  → Commit → chờ deploy.

 BƯỚC 2 — KIỂM TRA BIẾN MÔI TRƯỜNG TRÊN VERCEL
================================================================
Project oes → Settings → Environment Variables, đối chiếu:
  GOOGLE_SERVICE_ACCOUNT_JSON : (giữ nguyên như hiện tại)
  GOOGLE_DRIVE_FOLDER_ID      : phải là 1kvdJX6Va5OcS_OOQ8JN7hYh3aRRSFR5M
                                (thư mục ở Bước 0 — nếu đang khác thì
                                sửa rồi nhớ Redeploy)
  ADMIN_CCCDS                 : (giữ nguyên)
  SESSION_SECRET              : khuyến nghị có (chuỗi random dài bất kỳ);
                                thiếu cũng không chết — R4 tự phái sinh khóa ổn định
  DATA_FILE_SUFFIX            : KHÔNG cần đặt (tự mặc định "Vercel" trên Vercel)

Sau khi thêm/sửa biến → Deployments → nút ⋯ → Redeploy.

================================================================
 BƯỚC 3 — XÁC MINH SAU DEPLOY (làm đủ 4 bước)
================================================================
1. Mở https://<domain>/api/health
   → phải thấy  "ok": true, "build": "OES-VERCEL-R5"
2. Đăng nhập admin → tạo đề/đăng ký user thử → nộp 1 bài thử.
3. Mở thư mục Drive ở Bước 0 → thấy usersVercel.json,
   resultsVercel.json CÓ DỮ LIỆU MỚI (mở file xem nội dung),
   còn users.json / results.json GIỮ NGUYÊN — bên render.com không bị động đến.
4. Vào thi thử lại → không còn báo "Phiên đăng nhập hết hạn hoặc
   không hợp lệ" (bản R4 đã kèm trong R5).

Lưu ý: bản Vercel sẽ KHÔNG thấy tài khoản đã đăng ký trước đây
trên hệ thống cũ (đó là chủ đích tách dữ liệu). Muốn giữ tài khoản
cũ → dùng PHƯƠNG ÁN B ở Bước 0. Admin đăng ký trên bản Vercel luôn
là người dùng ĐẦU TIÊN đăng ký khi usersVercel.json còn trống.

 NHẬN DIỆN NHANH CÁC TRIỆU CHỨNG
================================================================
- /api/health thấy "build": "OES-VERCEL-R4" → mới bản R4, chưa R5 → upload lại.
- Nộp bài không lưu / Drive báo lỗi dung lượng → thiếu 3 file
  *Vercel.json trong thư mục → làm lại Bước 0.
- /api/health trả 401 "Phiên đăng nhập hết hạn..." → repo còn thiếu
  file bản mới (public.routes.js...) → dùng CÁCH A upload toàn bộ.
- Trang chủ 404 → deployment bị xóa/chưa có bản production → xem tab Deployments.
- 500 FUNCTION_INVOCATION_FAILED → src/app.js chưa export hàm → upload toàn bộ theo CÁCH A.
