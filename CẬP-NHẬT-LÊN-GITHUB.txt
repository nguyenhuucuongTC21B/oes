 BƯỚC 4 — XÁC MINH SAU DEPLOY (làm đủ 4 bước)
================================================================
1. Mở https://<domain>/api/health
   → phải thấy "ok": true, "build": "OES-VERCEL-R6"
   (nếu vẫn thấy R5/R4 → deployment chưa chạy code mới → làm lại
   Bước 1+2, kiểm tra đủ file ở mục 4 của Bước 1).
2. Mở trang đăng ký → đăng ký tài khoản THỬ (CCCD mới) → phải
   thành công, KHÔNG còn báo "Phiên đăng nhập hết hạn".
   ⚠️ Nếu CCCD đã đăng ký rồi → hệ thống báo "Số CCCD này đã được
   đăng ký" (409 — đúng logic) → dùng tab ĐĂNG NHẬP.
3. Đăng nhập admin → tạo đề/xem kết quả; mở thư mục Drive
   https://drive.google.com/drive/u/0/folders/1kvdJX6Va5OcS_OOQ8JN7hYh3aRRSFR5M
   → dữ liệu đổ vào usersVercel.json / resultsVercel.json, còn
   users.json / results.json GIỮ NGUYÊN (bên render.com không bị
   động đến).
4. Vào thi thử → nộp bài → kết quả lưu bình thường.
